## Opis domene
Projekt se svodi na praćenje, upravljanje i oprtimizaciju gospodarenja otpadom i recikliranja materijala, kako bi se zadovoljili trendovi zaštite okoliša i manjeg zagađenja otpadom.

## Specifikacija projekta
Programski proizvod treba omogućiti bolje praćenje dostupnih materijala i recikliranja. Također, treba omogućiti korisnicima jednostavan pristup informacijama o reciklabilnim materijalima, rezervacijama te statističkim podacima o kupljenim materijalima i stanju skladišta.
